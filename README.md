# Amira Labs plug-ins

Installers of each version of the Amira Labs plug-ins (ATRI8, RAYO II, Korale), one release per version: `atri8-1.0.0`, `rayo-1.0.0`...

The newest version of each one is announced in `versions.json` of [elevo-licenses](https://github.com/neuradataai-bot/elevo-licenses), which the plug-ins read once a day.
